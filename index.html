База для новичков

Короткая шпаргалка: из чего состоит страница, как её украсить и как оживить кнопкой.

Как пользоваться

01

Вставь код

Скопируй HTML, CSS и JS в соответствующие вкладки. Если HTML уже целый документ — компилятор аккуратно добавит стили и скрипт.

02

Запусти

Кнопка «Запустить» собирает три части в одну страницу и показывает результат справа. Ошибки JS появятся в консоли.

03

Сохрани файл

Загрузи картинки, в коде укажи путь images/имя.png. «Сохранить проект» или ZIP запишет HTML вместе с файлами — эту папку можно сразу залить на GitHub.
