# Kodify Compiler

Корпоративный HTML-компилятор в стилистике [kodify.online](https://kodify.online/): вставь HTML / CSS / JS, запусти превью и сохрани готовый `.html` в выбранную папку.

## Локальная проверка

Нужен локальный сервер (выбор папки в браузере не работает через `file://`).

```bash
python -m http.server 5500
```

Открой http://localhost:5500/

- **Запустить** или `Ctrl + Enter` — собрать и показать результат
- **Выбрать папку** → **Сохранить в папку** или `Ctrl + S`
- Chrome / Edge умеют писать прямо в папку; в остальных браузерах файл скачивается

## GitHub Pages (после правок)

1. Создай репозиторий и загрузи файлы из этой папки (`index.html` должен быть в корне).
2. GitHub → **Settings → Pages → Deploy from a branch** → `main` / `/ (root)`.
3. Сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.
